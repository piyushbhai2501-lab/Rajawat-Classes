# Rajawat Ascent

PROJECT: RAJAWAT CLASSES — PREMIUM MULTIPAGE EDUCATIONAL WEBSITE



Build a complete, production-quality, premium multipage website for Rajawat Classes, a coaching institute in Bindayaka, Jaipur, Rajasthan. The website must look like a professionally designed, established educational brand—not a generic coaching template. Prioritize visual excellence, student trust, responsive design, smooth premium animations, accessibility, performance, SEO, and real functionality.



Study all uploaded reference images carefully. Use them to understand the institute's branding, faculty photographs, chemistry specialization, courses, educational materials, and contact information. Improve the presentation significantly while preserving the institute's identity.



1. BRAND IDENTITY & DESIGN SYSTEM



Brand name: Rajawat Classes

Tagline: "Your Success, Our Commitment!"

Chemistry tagline: "Chemistry Is All About Data and Feel."



Create a sophisticated, memorable educational brand identity using:



- Primary background: Midnight navy (#101A33).

- Secondary color: Deep royal blue (#173A70).

- Accent: Premium golden yellow (#FFC928).

- Main light background: Warm white (#FAFAFC).

- Secondary light sections: Soft blue-gray (#F1F4F9).

- Body text: Dark charcoal (#20283A).

- Use red (#EF343B) sparingly for important calls to action, inspired by the existing logo.



Maintain excellent color contrast and a consistent design system. The website must feel premium, modern, confident, academic, welcoming, and trustworthy.



Use a refined font pairing such as Manrope or Plus Jakarta Sans for headings and Inter for body text. Use bold, oversized editorial headlines, elegant typography, generous whitespace, precise alignment, sophisticated borders, subtle shadows, tasteful gradients, and consistent spacing.



Create a clean, modern Rajawat Classes wordmark or geometric logo inspired by the uploaded branding. If a usable original logo is available, preserve it rather than replacing it unnecessarily. Create a matching favicon.



Avoid childish illustrations, excessive gradients, excessive rounded cards, random colors, generic AI-looking layouts, unnecessary decorative elements, and overcrowded sections.
